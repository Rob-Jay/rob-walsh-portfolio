## This portfolio
This site is built with Next.js and React and deployed on Vercel. The page is server-rendered. Questions typed into rob-gpt go through a server-side route to Claude Haiku, which answers only from Rob's notes. The source is on GitHub at github.com/Rob-Jay/rob-walsh-portfolio.
