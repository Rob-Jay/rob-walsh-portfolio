## This portfolio
This site is built with Next.js and React and deployed on Vercel. Questions typed into rob-gpt go through a server-side route to Claude, which answers from Rob's notes with streaming. It also includes a side-scroller game called Dev Run. The source is on GitHub at github.com/Rob-Jay/rob-walsh-portfolio.
